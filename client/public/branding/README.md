# Brand sources

The public Copilot Connection project links to https://copilotfireside.chat/ from
https://github.com/Copilot-Connection/CCWeb2/blob/main/src/data/projects.ts.
The Copilot Connection banner and favicon were inspected, but are not substituted
for the distinct Fireside Chat brand.

The Fireside site's actual images are used here for the requested brand continuity:

- `fireside-scene.jpg`: https://copilotfireside.chat/assets/images/image04.jpg
  (the show's existing fireplace photograph; captioned as brand imagery, not the
  Christmas event's confirmed panel).

This is existing brand artwork, not a newly generated image. Artwork remains the
property of its original owner; its presence does not license unrelated reuse.
The Christmas UI treatment and simple flame UI icon are new, not an official logo.
No distinct Fireside logo asset was identified: the small image01.png on the
reference site is the Microsoft Copilot product mark, so it is not mislabelled or
republished here as a Fireside Chat logo.
No past guest photograph, name or event
details from the reference site are represented as this event's confirmed panel.

The audience's charcoal surface, gold accents, restrained network-line motif and
uppercase display wordmark take their direction from the reference site.
The line illustration is newly authored, not copied artwork.

Krona One, the reference site's display typeface, is self-hosted at
`../fonts/krona-one.ttf` so visitors do not contact a third-party font service.
Source: https://fonts.google.com/specimen/Krona+One
Font binary: https://fonts.gstatic.com/s/kronaone/v15/jAnEgHdjHcjgfIb1ZcUCMQ.ttf
The SIL Open Font License is included at `../fonts/OFL.txt`, sourced from
https://github.com/google/fonts/blob/main/ofl/kronaone/OFL.txt.

Inter, the reference site's body typeface, is also self-hosted, including its
variable weights for text and controls:
`../fonts/inter-variable.woff2`, from
https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2.
Its SIL Open Font License is included at `../fonts/Inter-OFL.txt`, from
https://github.com/rsms/inter/blob/master/LICENSE.txt.
